# Rocket Journal — Claude Context

## What This App Is

A multi-modal journaling app for iOS/Android. Users can journal through three modes:
- **Reflect** — text/voice entry prompted by a daily question fetched from Supabase
- **Rant** — continuous voice recording with AI cleanup (Gemini punctuates raw speech)
- **Scribble** — freehand drawing canvas

After a session ends, an **AI-generated analysis screen** shows the user an AI title, detected moods (Yale Mood Meter), an insight, and topic tags — all generated by Gemini via a Supabase Edge Function.

Auth is magic link (passwordless email) via Supabase. All entries are stored locally in Hive first, then synced to Supabase when online (offline-first).

- **Cards:** White fill, black border 1.5px, `BorderRadius.circular(8)`
- **Mood/topic chips:** Rounded pill (radius 20), 12px horizontal + 6px vertical padding

## AI Pipeline

```
Voice input → STT (Deepgram / manual_speech_to_text)
           → Gemini punctuate-transcript Edge Function (fixes punctuation/capitalization)
           → Entry saved to Hive + Supabase

Entry text → Gemini analyze-entry Edge Function
           → { title, moods (Yale Mood Meter labels), insight, topics }
           → EntryAnalysisScreen rendered
```

**Mood source:** `assets/yale_mood_meter.csv` — Gemini is constrained to only pick from this list.
**Emoji mapping:** Dart `Map<String, String>` in `entry_analysis_service.dart`; unmapped moods show label only.

## Navigation Flow

```
App launch
  → GoRouter checks: onboarding complete? → authenticated? → display name set?
  → /onboarding/welcome → /onboarding/actions → /onboarding/privacy
  → /login → /magic-link-sent → (deep link callback) → /ask-name → /home

/home (tab bar)
  → Reflect tab → ReflectScreen → _endSession() → EntryAnalysisLoadingScreen → EntryAnalysisScreen → /home
  → Rant tab   → RantRecordingScreen → (save) → EntryAnalysisLoadingScreen → EntryAnalysisScreen → /home
  → Scribble   → ScribbleScreen → saved confirmation → /home
  → History    → HistoryScreen → HistoryEntryDetailScreen
  → Profile    → ProfileScreen
```

## Supabase Setup Notes

- **Edge Function env var required:** `GEMINI_API_KEY` (set via `supabase secrets set GEMINI_API_KEY=...`)
- **Deploy commands:**
  - `supabase functions deploy punctuate-transcript`
  - `supabase functions deploy analyze-entry`
- **Auth:** Magic link with deep link redirect `journalapp://auth/callback`
- **Tables:** `journal_entries`, `reflection_prompts` (with `is_active` flag)
